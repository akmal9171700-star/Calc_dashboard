# Калькулятор вознаграждения агентов

Бесплатный веб-калькулятор: агент выбирает категорию, регион, статус месячного плана и вводит
количество подключений — получает вознаграждение за 1-й, 2-й и 3-й месяцы с разбивкой.
Тарифы, цены и ставки хранятся в Google Sheets: поменяли в таблице — калькулятор обновился
(в течение 5 минут), код и GitHub трогать не нужно.

## Что внутри

| Файл | Назначение |
|---|---|
| `app.py` | интерфейс (Streamlit), русский и узбекский |
| `calc.py` | расчёт вознаграждения (точная арифметика, без округления по пути) |
| `sheets.py` | чтение Google Sheets, проверка данных, запасной вариант |
| `texts.py` | тексты интерфейса на двух языках |
| `data/fallback.json` | резервная копия правил (используется, если таблица недоступна) |
| `Google_Sheets_шаблон.xlsx` | готовая таблица для администрирования |
| `tests/` | автотесты (расчёты из CALC.xlsx, проверка данных, интерфейс) |
| `.streamlit/secrets.toml.example` | образец настроек доступа (настоящий ключ в GitHub не кладём) |

## Часть 1. Google-таблица

1. Откройте Google Drive → **Создать → Загрузка файла** → выберите `Google_Sheets_шаблон.xlsx`.
2. Откройте загруженный файл, затем **Файл → Сохранить как Google Таблицы**. Откроется настоящая Google-таблица (xlsx можно удалить).
3. Не переименовывайте листы **Тарифы**, **Ставки**, **Настройки** и заголовки колонок.
4. Скопируйте ID таблицы из адресной строки: `docs.google.com/spreadsheets/d/`**ЭТО_ID**`/edit`.

## Часть 2. Ключ доступа (сервисный аккаунт, только чтение)

1. Откройте https://console.cloud.google.com и войдите тем же Google-аккаунтом. Создайте проект (любое имя).
2. **APIs & Services → Library** → найдите **Google Sheets API** → **Enable**.
3. **APIs & Services → Credentials → Create credentials → Service account** → любое имя → **Create and continue → Done**.
4. Откройте созданный аккаунт → вкладка **Keys → Add key → Create new key → JSON**. Скачается файл с ключом. Храните его в секрете и никому не отправляйте.
5. В скачанном файле найдите `client_email` (вида `имя@проект.iam.gserviceaccount.com`).
6. В Google-таблице нажмите **Настройки доступа** и добавьте этот адрес с ролью **Читатель**. Общий доступ «всем по ссылке» **не включайте**.

## Часть 3. GitHub

1. Зарегистрируйтесь на https://github.com → **New repository** → имя `agent-calculator` → **Public** → **Create repository**.
   В репозитории только код и резервная копия тарифов (`data/fallback.json`), ключей там нет. Если ставки конфиденциальны, сообщите об этом до публикации.
2. В репозитории: **Add file → Upload files**. Распакуйте архив проекта и перетащите **всё содержимое** папки (включая папки `data`, `tests`, `.streamlit`).
   Если папки `.streamlit` не видно, включите показ скрытых файлов (Windows: Вид → Показать → Скрытые элементы; Mac: Cmd+Shift+.).
3. Нажмите **Commit changes**.

## Часть 4. Публикация на Streamlit Community Cloud

1. Откройте https://share.streamlit.io → **Continue with GitHub** → разрешите доступ.
2. **Create app → Deploy a public app from GitHub**. Repository: `ваш_логин/agent-calculator`, Branch: `main`, Main file path: `app.py`. При желании задайте адрес приложения.
3. Откройте **Advanced settings → Secrets** и вставьте (значения возьмите из скачанного JSON-файла: `"ключ": "значение"` превращается в `ключ = "значение"`):

```toml
[sheets]
spreadsheet_id = "ID_ТАБЛИЦЫ"

[gcp_service_account]
type = "service_account"
project_id = "..."
private_key_id = "..."
private_key = "-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
client_email = "...@....iam.gserviceaccount.com"
client_id = "..."
token_uri = "https://oauth2.googleapis.com/token"
```

   `private_key` копируйте целиком вместе с кавычками, символы `\n` оставьте как есть.
4. Нажмите **Deploy** и подождите 2–5 минут. Готовая ссылка и есть адрес калькулятора для агентов.
5. Проверка: если вверху **нет** жёлтого предупреждения, данные идут из таблицы. Если оно есть, откройте **Manage app → Logs** и найдите строку «Не удалось получить правила из Google Sheets» — в ней причина (чаще всего таблица не открыта для сервисного аккаунта или неверный ID).

## Как менять тарифы и ставки

Все изменения — только в Google-таблице. Агенты увидят их не позже чем через 5 минут.

**Лист «Тарифы»**: `Тариф`, `Тип` (BUNDLE или обычный), `Цена с НДС`, `Основной тариф` (только для Bonus: название основного тарифа), `Фиксированное вознаграждение` (только для Bonus, за 1-й месяц), `3-й месяц` (да/нет: платится ли 3-й месяц), `Активен` (да/нет), `Порядок` (порядок на экране).
Новый тариф — новая строка. Временно убрать тариф — поставить «нет» в колонке «Активен».

**Лист «Ставки»**: `Тип`, `Категория`, `План` (да/нет/\*), `Регион`, `Ставка 1 мес`, `Ставка 2 мес`, `Ставка 3 мес`.
Знак `*` означает «любое значение». Если подходит несколько строк, берётся самая конкретная (с меньшим числом `*`). Пустая ставка 3-го месяца означает, что месяц не оплачивается. Ставки вводите в процентах: `65%` или `65`.

**Лист «Настройки»**: `НДС` (в колонке «Значение»), а также категории и регионы: `Код` (латиницей, его используют листы «Ставки»), названия `Рус` и `Узб`.

**Что проверяется автоматически**: числа, ставки от 0 до 100 %, повторы тарифов, связь Bonus с основным тарифом, наличие ставки для каждого сочетания тип/категория/план/регион. Если в таблице ошибка, калькулятор продолжает работать на последних корректных данных, а агент видит предупреждение.

## Ограничения бесплатного хостинга

- Приложение «засыпает», если на него несколько часов никто не заходит (по информации Streamlit — около 12 часов; условия могут меняться). Первый посетитель нажимает кнопку **Yes, get this app back up**, запуск занимает около минуты.
- Данные приложение читает из таблицы не чаще раза в 5 минут, поэтому лимиты Google не мешают.
- Резервная копия `data/fallback.json` обновляется вручную (загрузкой нового файла на GitHub). Она нужна только на случай, когда таблица недоступна.

## Допущения, принятые при разработке

- Месячный план отмечает сам агент. При «выполнен» применяются ставки категории, при «не выполнен» — ставки региона (для всех категорий).
- 3-й месяц платится только по Salom Pro (флаг в листе «Тарифы»).
- Bonus SIM: 1-й месяц — фикс × количество (без пересчёта НДС), 2–3-й месяцы — ставка × цена без НДС основного тарифа × количество.
- Обычные тарифы и Mini Voice считаются по ставке региона от цены без НДС, без 3-го месяца. Mini Voice в исходном файле не имел типа, в шаблоне ему задан тип «обычный».
- Mobile Lux и Mobile Elite считаются как BUNDLE по общим ставкам, без Bonus SIM.
- Старая система (SUPER LUX, доплата за 1-й месяц) и сравнение «Фарки» в калькулятор не включены.
- Округление: расчёт точный, итоги по месяцам округляются до целого сума (0,5 — вверх), общий итог — сумма округлённых месяцев.
- Узбекские тексты в `texts.py` и названия на листе «Настройки» стоит проверить носителю языка.
